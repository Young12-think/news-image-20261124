## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. The program copies `entry.png` (1024 by 1024 pixels, under 1 MiB) to `/output/entry.png`, deterministically — both runs write the same bytes.
